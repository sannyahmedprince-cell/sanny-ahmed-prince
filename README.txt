======================================

Files
-----
index.html  Main website content

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to preview it in your browser.
4. Keep all three files in the same folder.

BEFORE PUBLISHING
1. Confirm every CV detail and employment date is accurate.
   The displayed name is spelled exactly: Sanny Ahmed Prince.
   The email address is retained from the CV; verify it before publishing.
2. In index.html, replace the Facebook link href="#" (id="facebook-link") with your actual public Facebook profile URL.
3. Decide whether you want your phone number visible publicly. If not, remove the phone row from the Contact section.
4. Add your preferred professional portrait if you want one. This design currently uses a typographic monogram, so no image file is required.
5. Do not upload sensitive personal information such as date of birth or home address.

PUBLISHING FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. sanny-portfolio.
3. Upload index.html, style.css, and script.js to the repository's root.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for GitHub Pages to publish the site. The public URL appears in Settings > Pages.

NOTES
- The site uses Google Fonts, which need an internet connection to load. It will fall back to system fonts if unavailable.
- This is a static portfolio. The contact form is intentionally omitted; email and phone links work without a server.
